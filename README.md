# CodeAlpha Hangman Game

## Project Description
The Hangman Game is a simple text-based word guessing game developed using Python. The player must guess a hidden word one letter at a time.

## Features
- Selects a random word from five predefined words.
- Allows a maximum of six incorrect guesses.
- Displays correctly guessed letters.
- Prevents repeated guesses.
- Validates user input.
- Displays win or loss messages.

## Technologies Used
- Python
- Random module
- VS Code

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `python hangman.py`.

## Concepts Used
Lists, strings, loops, conditional statements, user input, and random selection.
